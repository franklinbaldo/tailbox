# TailBox 0.1.0

- Add a Rust supervisor and a native Go/tsnet engine for unprivileged Windows.
- Expose application-scoped SOCKS5 and HTTP CONNECT proxies on loopback.
- Persist the embedded Tailscale identity under `%LOCALAPPDATA%\TailBox`.
- Supervise the engine with a Windows Job Object.
- Package the Windows x64 executables with license and manifest metadata.
- Verify release archives with a published SHA-256 sidecar.
- Preserve the LiteBox proof as an explicitly experimental optional backend.
